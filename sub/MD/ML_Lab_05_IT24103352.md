### A.2 Sigmoid Function

Logistic Regression first calculates a linear score:

$$z = \theta_0 + \theta_1 x$$

The Sigmoid function converts the score into a probability:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**Task 1**

1. Implement the Sigmoid function from scratch using NumPy.
2. Initialize $\theta_0 = 0$ and $\theta_1 = 0$.
3. Calculate the predicted probabilities for all observations.
4. What probability is produced for each observation at the initial parameter values?
5. Why is the Sigmoid function required in Logistic Regression?

> 4. Every Observation has a probability of p = 0.5. This happens initially: theta1 = 0, theta2 = 0. Therefore, z = 0 and sigma(0) = 0.5.
>
> 5. The linear equation can produce any real value from negative infinity to positive infinity. However, classification requires a probability between 0 and 1. The Sigmoid function maps the linear score to the probability range. Therefore, Logistic Regression can interpret the result as the probability of belonging to class 1, which, in this problem, means "Pass".

### A.3 Log-Loss / Binary Cross-Entropy

Use the Binary Cross-Entropy cost function:

$$J(\theta) = -\frac{1}{m}\sum_{i=1}^{m}\left[y_i \log(h_i) + (1-y_i)\log(1-h_i)\right]$$

where:

$$y_i = Y$$
$$h_i = Sigmoid(z)$$

**Task 1**

1. Implement the Log-Loss function from scratch.
2. Calculate and display the initial cost.
3. What does a smaller Log-Loss value indicate?
4. What happens to the loss when the model confidently makes an incorrect prediction?
5. Why is a cost function required during model training?

> 3. A smaller Log-Loss means that the predicted probabilities are closer to the correct class labels. Therefore, the model is making better predictions. A value closer to zero generally indicates better performance.
>
> 4. The Log-Loss becomes very large. For example, if the actual class is 1 but the model predicts a probability close to theta, the model is confidently wrong. Log-Loss heavily penalizes this type of mistake.
>
> 5. A cost function measures how inaccurate the model's predictions are. Gradient Descent uses the cost to determine how the parameters should be adjusted. During training, the objective is to minimize the cost. Without a cost function, the model would have no mathematical measure telling it whether its predictions are improving.

### A.4 Gradient Descent

Gradients:

$$\frac{\partial J}{\partial \theta_0} = \frac{1}{m}\sum_{i=1}^{m}(h_i - y_i)$$

$$\frac{\partial J}{\partial \theta_1} = \frac{1}{m}\sum_{i=1}^{m}(h_i - y_i)x_i$$

Update rule:

$$\theta_j := \theta_j - \alpha \frac{\partial J}{\partial \theta_j}$$

**Task 1 – Train the Model**


**Task 2 – Observe Convergence**

2. What happens to the loss as training progresses?
3. What does it mean when the loss begins to stabilize?
4. What could happen if the learning rate is too large?
5. What could happen if the learning rate is too small?

> 2. The Log-Loss gradually decreases as Gradient Descent updates the parameters. This shows that the predictions are becoming closer to the actual target values.
>
> 3. When the loss starts to stabilize, the parameter updates are producing very small improvements. This indicates that Gradient Descent is approaching a minimum of the cost function and the model is converging.
>
> 4. If the learning rate is too large, Gradient Descent may take excessively large steps. It can overshoot the minimum and cause the loss to oscillate or even increase instead of converging.
>
> 5. If the learning rate is too low, Gradient Descent will still move toward the minimum, but very slowly. Therefore, many more iterations will be required for the model to converge.

## Part C — Understanding the Concepts

Answer each question analytically in 3-6 sentences: justify your reasoning rather than stating a definition, and where relevant, ground your answer in what you actually observed in the Sigmoid Explorer, Gradient Descent Visualization, or kNN Explorer above.

**1. If Mean Squared Error were used instead of Log-Loss to train this Logistic Regression model, explain, by reasoning about the shape of each cost surface, why Gradient Descent would struggle to reliably reach the minimum.**

> Using Mean Squared Error together with the Sigmoid function can create a non-convex cost surface containing flatter regions and possible local minima. This makes Gradient Descent less predictable because it can move slowly in flat regions or fail to approach the global minimum reliably. Log-Loss, on the other hand, gives Logistic Regression a well-behaved convex cost surface. In the Gradient Descent visualization, the Log-Loss decreased steadily as the parameters were updated, illustrating why it is suitable for optimization. Therefore, Log-Loss gives Gradient Descent a more reliable path toward the optimal parameters.

**2. A spam filter and a cancer-screening classifier both output a probability. Argue, in terms of the relative cost of false positives versus false negatives, whether each should use a threshold above, below, or exactly at 0.5.**

> A spam filter may use a threshold **above 0.5** if incorrectly marking an important legitimate email as spam is considered more costly than allowing some spam into the inbox. A higher threshold means the classifier requires stronger evidence before labeling an email as spam. In cancer screening, the threshold should generally be **below 0.5**, because a false negative could mean failing to identify a patient who actually has cancer. Lowering the threshold increases sensitivity and makes the system more likely to flag possible cases for further testing. Therefore, the appropriate threshold depends on the relative consequences of false positives and false negatives.

**3. Using what you observed in the kNN Explorer, explain how increasing k moves the model along the bias-variance trade-off, and justify what the decision boundary would look like if k equaled the total number of training points.**

> When k is small, such as k=1, kNN is highly sensitive to individual training examples, resulting in **low bias but high variance**. Increasing k averages the decision across more neighboring observations, making the prediction smoother and reducing variance, but increasing bias. This behaviour can be observed in the kNN Explorer because different values of k can change Q's predicted class. If k equals the total number of training observations, every query point would be classified according to the majority class of the entire dataset. The resulting decision boundary would therefore become extremely simple and would largely ignore local clusters.

**4. A classmate claims: "kNN is strictly better than Logistic Regression because with k=1 it can always achieve 100% accuracy on the training set." Critically evaluate this claim, considering both training and unseen data.**

> The claim is incorrect because high training accuracy does not guarantee good performance on unseen data. With k=1, kNN can effectively memorize the training observations, giving it very low training error. However, this makes the model highly sensitive to noise and unusual observations and can result in overfitting. A slightly larger k may generalize better even if its training accuracy is lower. Logistic Regression may also outperform kNN when the true relationship between features and classes is approximately linear, so neither algorithm is strictly better in every situation.

**5. Logistic Regression produced a straight decision boundary in this lab, while kNN's boundary could bend around clusters of points. Explain the mathematical reason for this difference by referring to each model's hypothesis function.**

> Logistic Regression models probability using:
>
> $$P(Y=1|X) = \sigma(\theta_0 + \theta_1 x_1 + \theta_2 x_2 + \cdots)$$
>
> At a threshold of 0.5, the decision boundary occurs when the linear expression equals zero, producing a straight line in a two-dimensional feature space. kNN does not learn a fixed linear equation; instead, it determines the class of each query from the labels of nearby training observations. Because different neighborhoods can contain different class majorities, the kNN decision boundary can bend and form irregular shapes around clusters. Therefore, Logistic Regression has a parametric linear boundary, while kNN creates a flexible, data-dependent boundary.
