## 1. Types of Data

| Example | Data Type | Simple Justification |
|---|---|---|
| A customer database stored in MySQL | Structured Data | Stored in tables (rows + columns). Easy to search and analyse. |
| JSON data returned from a REST API | Semi-structured Data | Has a structure (key–value pairs) but not fixed like tables. |
| CCTV surveillance video | Unstructured Data | No fixed format. Raw pixels, continuous frames. |
| Emails containing headers and message bodies | Semi-structured Data | Headers have structure, message body is free text. |
| An Excel spreadsheet containing student marks | Structured Data | Organized into rows and columns. |

**b. Which type of data is easiest for traditional ML?**

Structured data. Because it is already organized into rows and columns, making it easy for algorithms to process.

**c. Why is unstructured data more challenging?**

Because it has no fixed format. Algorithms cannot directly understand images, videos, or raw text. They require extra preprocessing, feature extraction, or deep learning.

## 2. Identify the learning paradigm

| Scenario | Learning Type | Reason |
|---|---|---|
| Predicting whether a bank customer will default on a loan using labelled data | Supervised Learning | Labels (default / not default) are available. |
| Grouping customers by purchasing behavior without labels | Unsupervised Learning | No labels → clustering. |
| A robot learns to navigate a maze through rewards and penalties | Reinforcement Learning | Learns by trial-and-error using rewards. |
| Predicting house prices using historical housing data | Supervised Learning | Past prices act as labels. |
| Detecting unusual credit card transactions without labelled fraud cases | Unsupervised Learning (Anomaly Detection) | No fraud labels available. |

## 3. Model Performance (Underfitting, Overfitting, Good Fit)

**a. Identify each model**

| Model | Training Accuracy | Testing Accuracy | Conclusion | Reason |
|---|---|---|---|---|
| A | 99% | 61% | Overfitting | Performs well on training but poorly on testing. |
| B | 90% | 88% | Good Fit | Training and testing accuracies are close. |
| C | 58% | 55% | Underfitting | Both accuracies are low → model is too simple. |

**b. Main disadvantage of an overfitted model**

It performs poorly on new, unseen data. It memorizes the training data instead of learning patterns.

**c. One technique to reduce overfitting**

Use regularization (L1/L2) OR use dropout (in neural networks) OR collect more training data OR use cross-validation.

## 4. Dataset Splitting

**a. Primary purpose of dataset splits**

- Training set → used to teach the model
- Validation set → used to tune hyperparameters
- Test set → used to evaluate final performance on unseen data

**b. Advantages of using a separate test dataset**

- Gives a realistic estimate of how the model performs on new data
- Prevents over-optimistic results
- Ensures the model is not evaluated on data it has already seen
