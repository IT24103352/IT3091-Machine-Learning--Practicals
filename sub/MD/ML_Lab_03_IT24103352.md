## Part E – Case Study

**1. What is the main difference between the two preprocessing workflows?**

The main difference is the order of preprocessing and train-test splitting. In the first workflow, missing value imputation and feature scaling are applied to the entire dataset before splitting. In the second workflow, the dataset is first split into training and testing sets, then preprocessing is fitted only on the training dataset and applied to both training and testing datasets.

**2. Which workflow introduces data leakage?**

The first workflow introduces data leakage because preprocessing is performed using the entire dataset, including the test data.

**3. Why Should Preprocessing Be Fitted Only On Training Data?**

Preprocessing methods should be fitted only on the training dataset because the test dataset must represent unseen data. If information from the test data is used to calculate values such as mean, median, mode, minimum, maximum, or standard deviation, the model indirectly learns information from the test set. This can produce unrealistically high performance.

**4. Which workflow would you recommend for building a reliable machine learning model? Justify your answer.**

The second workflow is recommended for building a reliable machine learning model. The dataset should be split first, then preprocessing should be fitted only on the training data. The same fitted preprocessing steps should then be used to transform both training and testing data. This prevents data leakage and gives a more realistic estimate of model performance on unseen data.
